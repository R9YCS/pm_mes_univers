# Инструкция по настройке MES-системы 3D-печати

## Шаг 1: Настройка базы данных Supabase

1. **Откройте SQL Editor в вашем Supabase проекте:**
   - Перейдите на https://supabase.com/dashboard
   - Выберите ваш проект
   - В левом меню выберите "SQL Editor"

2. **Выполните миграцию:**
   - Скопируйте содержимое файла `/supabase/migrations/setup.sql`
   - Вставьте в SQL Editor
   - Нажмите "Run" или Ctrl+Enter

3. **Проверьте создание таблиц:**
   - Перейдите в "Table Editor"
   - Убедитесь, что созданы все таблицы в схеме `mes_minimal`:
     - persons
     - printers
     - order_statuses
     - materials
     - orders
     - print_logs
     - printer_maintenance
     - order_history

## Шаг 2: Настройка аутентификации

1. **Включите Email провайдера:**
   - Перейдите в "Authentication" → "Providers"
   - Убедитесь, что Email провайдер включен

2. **Настройте Email Templates (опционально):**
   - Перейдите в "Authentication" → "Email Templates"
   - Настройте шаблоны писем для регистрации и сброса пароля

## Шаг 3: Создание первого пользователя

### Вариант 1: Через веб-интерфейс (после запуска приложения)
1. Откройте приложение
2. Перейдите на вкладку "Регистрация"
3. Заполните форму:
   - ФИО
   - Email
   - Пароль (минимум 6 символов)
4. Нажмите "Зарегистрироваться"
5. Войдите с созданными учетными данными

### Вариант 2: Через Supabase Dashboard
1. Перейдите в "Authentication" → "Users"
2. Нажмите "Add user" → "Create new user"
3. Введите email и пароль
4. После создания пользователя, добавьте запись в таблицу `mes_minimal.persons`:
   ```sql
   INSERT INTO mes_minimal.persons (type, full_name, email, is_active)
   VALUES ('admin', 'Администратор', 'your-email@example.com', true);
   ```

## Шаг 4: Настройка прав доступа (Row Level Security)

По умолчанию RLS отключен для упрощения разработки. Для production рекомендуется:

1. **Включить RLS для всех таблиц:**
   ```sql
   ALTER TABLE mes_minimal.persons ENABLE ROW LEVEL SECURITY;
   ALTER TABLE mes_minimal.printers ENABLE ROW LEVEL SECURITY;
   ALTER TABLE mes_minimal.orders ENABLE ROW LEVEL SECURITY;
   -- и т.д. для остальных таблиц
   ```

2. **Создать политики доступа:**
   ```sql
   -- Разрешить аутентифицированным пользователям читать данные
   CREATE POLICY "Allow authenticated read" ON mes_minimal.orders 
   FOR SELECT TO authenticated USING (true);
   
   -- Разрешить аутентифицированным пользователям изменять данные
   CREATE POLICY "Allow authenticated write" ON mes_minimal.orders 
   FOR ALL TO authenticated USING (true);
   ```

## Шаг 5: Тестирование системы

1. **Войдите в систему** с созданными учетными данными

2. **Проверьте функционал:**
   - ✅ Канбан-доска заказов (создание, редактирование, перетаскивание)
   - ✅ Мониторинг принтеров (просмотр статусов, редактирование)
   - ✅ База клиентов (добавление, редактирование)
   - ✅ Управление пользователями (создание новых пользователей)
   - ✅ История заказов (просмотр логов и изменений статусов)

3. **Создайте тестовые данные:**
   - Добавьте несколько клиентов
   - Создайте заказы с разными статусами
   - Попробуйте перетащить карточку заказа между колонками Kanban

## Основные возможности системы

### 1. Канбан-доска заказов
- **Создание заказов:** Кнопка "Новый заказ"
- **Перетаскивание:** Drag & Drop для изменения статуса
- **Фильтрация:** По статусу, срочности, поиск по тексту
- **Автоматическое обновление:** Изменения сразу сохраняются в БД

### 2. Мониторинг принтеров
- **Просмотр статусов:** Работает, Простой, Ошибка, Обслуживание
- **Редактирование:** Клик по карточке для изменения статуса и параметров
- **Отображение текущих задач:** Какой заказ печатается на принтере

### 3. База клиентов
- **Управление контактами:** Телефон, Email, Примечания
- **История:** Автоматический подсчет заказов (через VIEW)
- **Поиск:** По имени, телефону, email

### 4. Управление пользователями
- **Роли:** Admin, Employee, Manager, Client
- **Создание через Auth:** Сотрудники создаются с логином/паролем
- **Статусы:** Активен/Неактивен

### 5. История заказов
- **Журнал изменений статусов:** Кто и когда изменил
- **Логи печати:** Успешные/неуспешные печати
- **Детальная информация:** Время, материалы, проблемы

## Важные особенности

### Автоматические триггеры
- **Генерация номера заказа:** ORD-2025-000001
- **История статусов:** Автоматическое логирование изменений
- **Обновление принтеров:** При изменении статуса заказа на "В печати"

### Безопасность
- **Аутентификация:** Обязательная для всех API endpoints
- **Хранение паролей:** Supabase Auth (bcrypt)
- **Токены:** JWT с автоматическим обновлением

## Устранение неполадок

### Ошибка "Unauthorized"
- Убедитесь, что вы вошли в систему
- Проверьте, что токен не истек (перезайдите)

### Ошибка при создании заказа
- Проверьте, что выбраны обязательные поля (Клиент, Название)
- Убедитесь, что в таблице `order_statuses` есть статус с code='new'

### Данные не загружаются
- Откройте консоль браузера (F12) и проверьте ошибки
- Проверьте подключение к Supabase
- Убедитесь, что таблицы созданы правильно

### Проблемы с drag-and-drop
- Убедитесь, что заказ имеет корректный status_id
- Проверьте, что статусы отсортированы по sort_order
